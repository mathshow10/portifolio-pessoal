O site que você está vendo. A ideia era algo minimalista, legível e fácil de manter.

## Como funciona

- Feito com **Astro**, gera HTML estático e quase nenhum JavaScript.
- Cada projeto é um arquivo `.md` em `src/content/projetos/`. Adicionar um projeto novo é criar um arquivo.
- Tema claro e escuro, respeitando a preferência do sistema.
- Publicado automaticamente no GitHub Pages a cada push na branch principal.
